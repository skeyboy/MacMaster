## 一、产品定位

**MacMaster** — 一款免费、开源、注重隐私的 macOS 系统维护工具。

**核心理念：**
- 轻量：菜单栏常驻，资源占用极低
- 安全：所有删除操作可撤回，敏感操作需确认
- 模块化：按需启用功能模块，不臃肿
- 原生：SwiftUI 原生体验，支持最新 macOS 特性
- 透明：开源代码，无后台数据收集

**目标用户：**
- 注重系统整洁的 macOS 用户
- 开发者（Xcode 缓存清理、二进制瘦身）
- 关注隐私安全的用户（摄像头/麦克风监控）
- 需要实时系统监控的高级用户

## 五、交互设计规范

### 5.1 核心交互原则

1. **安全第一**：所有删除操作先预览、再确认、可撤回
2. **渐进展示**：先展示概要，用户主动展开看详情
3. **即时反馈**：扫描进度实时展示，不阻塞 UI
4. **非模态**：尽量使用内联操作，减少弹窗打断

### 5.2 删除操作流程

```
用户选择 → 预览列表 → 确认删除 → 执行(进度条) → 完成(可撤回Toast)
                                  ↓
                           需要特权? → 弹出密码输入
                                  ↓
                           运行中App? → 提示先退出
```

### 5.3 撤回机制

- 删除完成后底部显示 Toast：「已清理 2.3 GB [撤回]」
- Toast 持续 10 秒，点击撤回可将文件从废纸篓恢复
- 历史记录中也可撤回最近 10 次操作

### 5.4 快捷键

| 快捷键 | 功能 |
|--------|------|
| ⌘, | 打开设置 |
| ⌘F | 搜索 |
| ⌘1-6 | 切换模块 |
| ⌘⌫ | 执行清理 |
| ⌘Z | 撤回上次操作 |

## 六、分阶段开发计划

### Phase 0：基础架构 (1-2 周)

**目标：** 搭建可运行的壳 App + 模块注册系统

**交付物：**
- [ ] Xcode 项目 + SPM 本地包结构
- [ ] 壳 App (NavigationSplitView 主窗口)
- [ ] ModuleRegistry 模块注册中心
- [ ] 2 个示例模块验证注册机制
- [ ] 基础主题系统 (颜色、字体)
- [ ] 基础设置页面

**验证标准：** App 启动后能显示主窗口，侧边栏可切换示例模块

### Phase 1：核心清理 (2-3 周)

**目标：** 实现 App 卸载和系统清理两大核心功能

**交付物：**
- [ ] Uninstaller 模块 — App 发现、关联文件扫描、卸载
- [ ] Cleaner 模块 — XML 规则引擎、系统/应用缓存扫描
- [ ] 文件安全删除 + 撤回系统
- [ ] XPC 特权 Helper (系统目录操作)
- [ ] 扫描进度 UI + 结果展示

**验证标准：** 能完整卸载一个 App 并清理残留，能扫描并清理系统缓存

### Phase 2：磁盘与监控 (2-3 周)

**目标：** 磁盘分析 + 系统监控菜单栏

**交付物：**
- [ ] 磁盘空间分析 — getattrlistbulk 高性能扫描
- [ ] Treemap 可视化 (SwiftUI 实现)
- [ ] 大文件查找
- [ ] 菜单栏监控 (CPU、内存、磁盘、网络)
- [ ] 监控 Widget 弹出面板

**验证标准：** 磁盘分析准确且性能好，菜单栏监控实时更新

### Phase 3：安全与高级功能 (2-3 周)

**目标：** 隐私监控 + 重复文件 + 浏览器清理

**交付物：**
- [ ] Guardian 模块 — 摄像头/麦克风监控
- [ ] 重复文件检测 (多级哈希算法)
- [ ] 浏览器隐私数据清理
- [ ] 登录项管理
- [ ] 通知系统

**验证标准：** 能检测到摄像头/麦克风使用并通知，能检测重复文件

### Phase 4：完善与发布 (2-3 周)

**目标：** 补充功能 + 打磨体验 + 准备发布

**交付物：**
- [ ] 电池/传感器监控
- [ ] 系统优化建议
- [ ] WidgetKit 桌面小组件
- [ ] 国际化 (中/英)
- [ ] 性能优化 + 内存优化
- [ ] DMG 安装包 + 自动更新
- [ ] 首页 Landing Page

**验证标准：** 完整功能可用，体验流畅，可发布 TestFlight
