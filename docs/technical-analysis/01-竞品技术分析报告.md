## 三、架构设计分析

### 3.1 Lemon Cleaner — 多进程 + Plist 模块注册

**架构特点：**
- **4 进程设计**：主 App + 状态栏 Monitor + 特权 Daemon (XPC) + 隐私保护进程
- **模块注册**：通过 `ToolConfig.plist` 定义模块，运行时 `NSClassFromString()` 动态实例化
- **清理引擎**：XML 规则驱动的扫描/清理系统，支持 12+ 清理类型
- **文件扫描**：使用 `getattrlistbulk()` 系统调用进行高性能批量目录遍历
- **重复文件**：多级算法 — 文件大小分桶 → 前 10MB MD5 → 全文件 CRC32
- **照片相似度**：50×50 灰度指纹 + 像素级比较

**关键设计模式：**
- Singleton 模式管理核心引擎
- Delegate 双委托模式传递扫描结果
- pthread + dispatch 并发扫描
- `@autoreleasepool` 控制内存峰值

### 3.2 Mole — Bash + Go 混合 CLI

**架构特点：**
- **双层架构**：Bash 脚本处理清理/卸载逻辑，Go 程序处理 TUI 可视化
- **模块化 Shell**：`lib/` 下按功能域分目录，source guard 防重复加载
- **Bubble Tea TUI**：Elm 架构 (Model-Update-View) 构建终端 UI
- **Spotlight 集成**：使用 `mdfind` 快速文件发现
- **安全系统**：受保护应用列表、路径验证、dry-run 模式、确认提示

**关键设计模式：**
- `set -euo pipefail` 严格错误处理
- 超时包装器防止命令挂起
- 操作日志审计
- 并发 goroutine 文件扫描 + channel 进度报告

### 3.3 Pearcleaner — SwiftUI 原生 + 多 Target

**架构特点：**
- **4 Target 设计**：主 App + Sentinel (FSEvents 监控) + Helper (XPC 特权操作) + Finder 扩展
- **两阶段流式加载**：Phase 1 快速展示 AppInfoMini → Phase 2 后台升级完整 AppInfo
- **60+ 路径扫描**：覆盖 Application Support、Caches、Containers、Group Containers 等
- **多策略匹配**：签名 Entitlements → Bundle ID → 名称模糊匹配 → Spotlight 元数据
- **撤回系统**：FileManagerUndo 追踪每次删除，支持持久化历史恢复（最多 10 次）
- **FSEvents 垃圾桶监控**：Sentinel 进程监控 Trash 目录，App 被删除时自动触发残留扫描

**关键设计模式：**
- `@MainActor` + `ObservableObject` 状态管理
- `TaskGroup` 结构化并发
- XPC + 代码签名验证保障安全
- `pear://` Deep Link + Finder 扩展 + CLI + Services 多入口
- AppStorageCodable 协议实现 Codable 持久化到 @AppStorage

### 3.4 Stats — AppKit 模块化监控

**架构特点：**
- **Reader-Widget 分离**：Reader 负责数据采集，Widget 负责展示，Module 负责编排
- **14 种 Widget 类型**：LineChart、BarChart、PieChart、Tachometer、Battery、Speed 等
- **10 个监控模块**：CPU、GPU、RAM、Disk、Net、Battery、Sensors、Bluetooth、Clock、Remote
- **LevelDB 时序存储**：图表历史数据使用 LevelDB 持久化，支持 TTL 自动清理
- **WidgetKit 扩展**：SwiftUI 实现桌面小组件，App Group 共享数据

**关键系统 API：**
| 数据类型 | API |
|----------|-----|
| CPU 使用率 | `host_processor_info()` |
| 内存 | `host_statistics64()`, `sysctl` |
| GPU | IOReport, IOPCIDevice |
| 磁盘 SMART | IOKit NVMe/ATA 直接读取 |
| 网络流量 | `getifaddrs()` |
| WiFi | CoreWLAN |
| 电池 | `IOPSCopyPowerSourcesInfo()`, IORegistry |
| 传感器/风扇 | SMC (AppleSMCInterface) via IOKit |
| 蓝牙 | CoreBluetooth + IOBluetooth + system_profiler |

**关键设计模式：**
- 并发队列 + barrier 写入实现线程安全
- `DispatchSourceTimer` 定时采集
- 睡眠/唤醒检测自动暂停/恢复采集
- 自定义 NSView + Core Graphics 图表绘制

### 3.5 OverSight — 隐私监控

**架构特点：**
- **双层检测**：属性监听器检测设备状态变化 + 日志流监控定位进程
- **版本自适应**：三套日志解析策略适配不同 macOS 版本
- **零扩展**：不使用 kext 或 system extension，纯用户空间实现

**核心 API：**
- `kAudioDevicePropertyDeviceIsRunningSomewhere` — 同时适用于音频和视频设备
- `CMIOObjectAddPropertyListenerBlock` — 摄像头设备状态监听
- 私有 `OSLogEventLiveStream` — 实时日志流获取进程 PID
- `SecCodeCopyGuestWithAttributes` — XPC 客户端代码签名验证

**关键技术：**
- 0.5 秒延迟关联设备事件与进程 PID
- 1 秒去重窗口防止重复通知
- 多策略进程路径解析 (`proc_pidpath` → `sysctl KERN_PROCARGS2`)
- 自删除 Daemon 模式 (忽略 SIGTERM + dispatch source)

## 四、核心算法提取

### 4.1 重复文件检测算法 (Lemon Cleaner)

```
Phase 1: 文件扫描 → 按大小分桶 (最小 200KB)
Phase 2: 排除 .svn/.git 目录
Phase 3: 前 10MB MD5 哈希 (dispatch_apply 并行)
Phase 4: >10MB 文件追加全文件 CRC32
Phase 5: 目录级比较 (递归子节点哈希对比)
最终哈希格式: "md5Str_crc"
```

### 4.2 照片相似度算法 (Lemon Cleaner)

```
Step 1: CGBitmapContext 缩放到 50×50
Step 2: 灰度转换 (red*38 + green*75 + blue*15) >> 7
Step 3: 计算 2500 像素平均值
Step 4: 按与平均值距离分 4 级量化
Step 5: EXIF 检测图片类型 (照片/截图/PS)
Step 6: 像素级比较 + 相邻匹配奖励 + 类型加成
```

### 4.3 高性能文件扫描 (Lemon Cleaner)

```
使用 getattrlistbulk() 系统调用批量读取目录属性
- O_RDONLY 打开目录
- val_attrs_t 结构体解析属性
- @autoreleasepool 控制内存 (27GB → 2.7GB)
- 跳过系统路径: /System/Volumes, /Volumes, /private/tmp/msu-
- 并发级别 = 处理器核心数
- pthread mutex + condition variable 线程协调
- 0.2 秒定时器进度汇报
```

### 4.4 两阶段流式加载 (Pearcleaner)

```
Phase 1 (快速):
  - 枚举 .app 包
  - 提取最小元数据 (名称、图标、路径)
  - 生成 AppInfoMini 对象
  - 立即渲染 UI

Phase 2 (完整):
  - 提取代码签名 Entitlements
  - 60+ 路径扫描收集关联文件
  - 孤儿文件反向查找
  - 流式升级为完整 AppInfo
```

### 4.5 系统健康评分 (Mole)

```
加权算法组合:
  - CPU 使用率权重
  - 内存压力权重
  - 磁盘使用率权重
  - 温度/热量权重
  - 电池健康权重
→ 综合 0-100 分健康值
```

## 六、关键技术选型建议

### 6.1 MacMaster 技术栈

| 层面 | 技术选型 | 理由 |
|------|----------|------|
| UI 框架 | SwiftUI + AppKit 混合 | SwiftUI 做主体 UI，AppKit 做菜单栏/窗口控制 |
| 模块化 | SPM 本地包 | 编译隔离、依赖清晰、复用性强 |
| 模块注册 | 协议 + 运行时注册 | 兼顾灵活性和类型安全 |
| 并发模型 | Swift Concurrency | async/await + TaskGroup + Actor |
| 文件扫描 | getattrlistbulk + 并发 | 参考 Lemon 的高性能方案 |
| 数据采集 | IOKit + sysctl + host_* | 参考 Stats 的成熟实现 |
| 隐私监控 | CoreAudio + CoreMediaIO | 参考 OverSight 的零扩展方案 |
| 持久化 | SwiftData / UserDefaults | 配置用 UserDefaults，数据用 SwiftData |
| 特权操作 | XPC + SMAppService | 参考 Pearcleaner/OverSight 的安全方案 |
| 图表绘制 | SwiftUI Charts + 自定义 | 系统框架优先，复杂场景自绘 |

### 6.2 最低系统要求

- macOS 14.0+ (Sonoma) — 使用最新 SwiftUI API、SwiftData、Swift Concurrency
- Apple Silicon 原生 + Intel 通用二进制
