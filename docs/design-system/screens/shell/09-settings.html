09e · 清理 tab —— 「清空删除历史」确认态（confirmationDialog）。 点 09c 的红色「清空删除历史」后置 confirmClearHistory = true 弹出。实机是 macOS 的 confirmationDialog（自窗口底部滑入的卡片），稿子按居中浮层画以便看清层级。按钮文案里的条数 与台账 N 同源（"清空 3 条记录" 的 3 = trashHistory.count，示例值）；「取消」role: .cancel。 说明文字逐字照抄 SettingsView.swift —— 它承诺的就是代码事实：只删记录，不碰废纸篓里的文件； 代价是「最近操作」里的撤回入口一并消失（FileTrashService.clearHistory 走同一个 record(.cleared) 出口，内存与磁盘台账同步清空）。台账为 0 时到不了这个弹窗（按钮已置灰），所以弹窗里不存在 "清空 0 条" 的形态。
