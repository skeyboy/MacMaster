卸载后遗症 = 正向扫描的逆问题。 正向问"这个应用的文件在哪"，反向问"这些文件是谁的"。判定一律偏保守——宁可漏报，不可错报： 只认反向域名形态（≥3 段点分、每段 ≥2 字符、总长 ≥10）；com.apple.* 永不入选（系统组件的缓存在 /System 里， 本来就没有"对应的已安装应用"）；派生标识算它主人的（com.foo.Bar.Updater / .Helper）； 末段是 UUID 的先剥掉再判形态（MMCleaner.ExclusionStoreTests.<uuid> 是每次运行换一个的实例产物，不是应用标识）； Containers / Group Containers 整条清单跳过（目录名是随机标识，没有名称可判）；系统域默认不扫。 所以这一屏的结论只是"高度可疑"：每一项默认不勾选，删除按钮在勾上之前是禁用的。
