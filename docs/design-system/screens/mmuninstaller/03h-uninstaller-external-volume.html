03h · 应用卸载 —— 应用装在另一块卷上（建议 2 的稿面，P54）。第一块：列表行 + 详情面板。 这一稿没有实机对应物：建议 2 的代码一行未落地（落地要单独授权），所以画板就是本轮唯一的现状， 不做「稿 ↔ 实机」对照。画板里的字面读数只有三样来自 P53 实拍：那条应用的挂载点与 /Applications 路径、8 KB（台账 size=8192 与卷内 du -sk 双向对上那一个数）、 「1 项残留 · 9 B」（照片 01 那一行）；其余（44 个应用、62.4 GB、下面四行的名字与大小与残留数）是稿面填充，不是读数。 chip 占这一格的理由沿用 03f 那一条：它会改变你接下来要做的事——不是"先退出"，而是"删完别急着拔盘"。 色用中性（--c-neutral-soft + 次级文字色，也就是 .badge.readonly 那一档），不用橙： 橙色在这张列表里已经是"这件事有代价"的专用色（运行中、疑似 brew 都占它）， 再来一枚橙会把那两条冲淡；而外接卷这条的真正代价要说在确认面板里，不靠颜色喊。 两枚、三枚并存时谁让步：这一行今天已经有四样东西抢宽度，chip 是 fixedSize() 不折不断， 大小有 layoutPriority(1)，能缩的只剩版本号（现状即尾截断）。 稿面量（1100px 窗口、CSS px，不是实机量）：.applist 那一列 268，第二行可用 138； 一枚 chip（41）+「版本 · 大小」放得下，就是画板第一行那个样子；两枚 chip 占掉 70~76， 「 · 大小」再占 ~40，留给版本号只剩 4.21 / 9.93px，而 2.1 / 0.13 要 18 / 24px—— 这不是"截断"，是整段看不见。所以这一稿的决定是：两枚 chip 并存时版本号直接不画， 画板里那两行（外接卷 + 运行中 / 外接卷 + brew）就是按这条画的，一枚 chip 都不撤。 版本号没有丢：详情面板「基本信息 → 版本」那一行一直在，列表行这一格让给"会改变你接下来做什么"的那两枚。 让步顺序：chip ＞ 大小 ＞ 版本号；万一三枚 chip 自己就挤不下，撤 brew 那一枚、留外接卷—— 取舍按"哪一条后果更不可补救"：brew 账本失真事后 brew reinstall 能纠，跨卷那份副本拔了盘就够不着。 实现那轮不许"先加上再看会不会挤"：上面那几个数已经量过一遍，挤不下是结论，不是待观察项。 详情面板本轮不加第三块色块（03f 那种 .runstate 形态）：位置事实「基本信息 → 所在文件夹」那行已经给了， 面板上缺的是"撤回条件"，而那是一件只有按下删除才会撞上的事，说在确认面板（画板 2）。 标题旁那枚 外接卷 徽章与来源徽章同住一排、各说一事（03f 画板 1 同规）。 侧栏那块容量条不动：它画的是启动卷，第二块卷不占这一格——位置信息由行的 chip 承担，页头副标题也不加"两块卷" （磁盘分析页那句「还有 N 卷可切」是那一页自己的口径，别抄过来）。

03h-2 · 第二块：确认面板里那句合同句，以及它排在谁上面。 这一屏是删除前的最后一站，而这一屏看不到路径——键值六行讲的是"这条应用是什么"（应用 / 来源 / 包名 / 本体 / 残留 / 合计）， 没有"所在文件夹"那一行。所以"它在另一块卷上"这件事在确认面板之前对用户是不存在的，这块 notice 是唯一把它说出来的地方； 稿面决定：挂载点写在 notice 第一句的括号里，不给面板加第七行 kv——kv 那一格的主语是"这条应用是什么"， 落点与撤回条件的主语是"删了之后会怎样"，后者跟着 notice 同住，面板才不会长出两半。 三块叠起来时不合并（下面那块是两枚提醒同屏的形状：外接卷 + 运行中）：三句说的对象各不相同——落点在哪块卷、进程还活着、brew 账本失真， 合成一块就要在同一句里换三个主语，那是把"哪一条在说什么"糊掉。顺序按补救代价从重到轻：外接卷 → 运行中 → brew； 现在代码里只叠两块（来源在前、运行在后，MMUninstaller.swift:740-746），这一版顺序是把"不可逆"顶到最上， 与现状不同，实现那轮要一并改。三块同时出现的形状真机上极罕见（brew 把 cask 装到第二块卷 + 正在运行）， 本轮不画三块，只把顺序规则定死；三块叠起来面板会不会顶到窗口下沿：没量，落地那轮实拍核。 合同句里不出现「残留」那半句：勾选残留一起删时的落点 P53 没量（台账那条 moved=1 只有本体）， 所以这句只敢讲本体——残留那一条等同卷推论，不是读数。 「撤不回来」不写成「已永久删除」：那一行字还在卷上，重挂盘按钮就回来（P53 三态实拍）， 这句吓人是假话；反过来也不写"可以放心拔盘"。提醒只说不拦：按钮仍是红色、仍是默认动作， 与 03f 那条纪律同规——外接卷不改变"这个包可以安全移走"，只改变"移走之后能不能再拿回来"。
